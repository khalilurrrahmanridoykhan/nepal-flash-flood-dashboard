# Geospatial method

## Route animation

The animated line connects cited event locations in chronological order. It explains sequence and direction only. The current release does not solve a hydraulic model and therefore does not publish flow velocity, water depth, inundation probability, or forecast arrival time.

## Advanced layers

- Satellite mode uses Esri World Imagery as geographic context, with provider attribution shown on the map. It is not represented as post-event imagery.
- Infrastructure markers identify facilities for which damage was reported. Marker placement is suitable for situational orientation, not engineering survey.
- District outlines in this MVP are generalized orientation envelopes, not authoritative administrative boundaries.

Future flood extents or before/after imagery must carry acquisition time, sensor, processing method, cloud-cover information, analyst, source license, and confidence before publication.
